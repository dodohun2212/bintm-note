# 결과 예시 (샘플 자료)

배포 앱의 **샘플 자료로 체험하기 → 개념 진단하기 → 예시 답 채우기 → 채점하기 → 공부 순서 보기**와 같은 순서로 `scripts/make_example.py`가 만든 결과입니다. 앱을 열지 않고도 앱이 만드는 결과물을 읽을 수 있습니다.

## 만든 조건과 잰 값

- 만든 날: 2026-11-10 · AI: 실제 AI(`claude-sonnet-5-5`)
- 실행 환경: Python 3.13.15 · anthropic 2.7.0(고정값 2.6.0) · pymupdf 2.1 · pydantic 2.14.3(고정값 2.13.5)
- 자료: `samples/`의 가상 강의자료(자료구조 8장 트리와 힙, 20쪽)와 녹음 대본
- 출제 점수 상위 3개: 힙의 삽입 연산 100점 · 이진 트리의 순회(전위·중위·후위) 94점 · 힙의 삭제 연산 90점
- 개념 13개, 교수님 강조 28개, 진단 11문제(서술형 6 · 객관식 5)
- 채점: 앎 4 · 헷갈림 4 · 모름 3
- 공부 순서: 지금 당장 2 · 다음 3 · 복습만 8 · 보완 설명 5개 · 요약 노트 13개(AI 9 · 짧게 4)
- 걸린 시간(같은 단계의 AI 호출은 동시에 부름): 분석(개념·교수님 강조) 57.0초 · 진단 문제 21.8초 · 채점 3.6초 · 보완 설명·요약 노트 34.7초 · 합계 117.2초
- AI 호출 31번 · 입력 93,905 · 출력 54,608 토큰

예시 답은 정답·반쯤 맞은 답·찍은 답·'모르겠어요'를 섞어 채운 것입니다(학생이 직접 푼 답이 아님). AI가 신호를 찾을 때마다 결과가 조금씩 달라질 수 있습니다. 출제를 보장하지 않습니다.
